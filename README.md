# ⏱️ Tempo de Busca no Array

Este projeto demonstra a medição do tempo de busca de um elemento específico (`"x"`) em arrays de diferentes tamanhos. 
O teste é executado por meio de um botão na interface, que gera um array aleatório, realiza a busca e exibe o tempo necessário para encontrar o elemento. 
É uma maneira simples de visualizar como o tempo de execução aumenta conforme o tamanho do array.

# 🚀 Funcionalidades
- **Criação de Array**: Gera um array de números aleatórios de tamanho variável e adiciona o elemento `"x"` no final para ser buscado.
- **Medição do Tempo de Busca**: A função `measureSearchTime` mede o tempo necessário para encontrar o elemento `"x"` no array.
- **Resultados Dinâmicos**: O tempo de busca para cada tamanho de array é exibido na tela assim que o teste é executado.
